# نظام نقل الطلاب 1448 — V2.0 COMPLETE

مدرسة عماد الدين زنكي المتوسطة

## ما الذي يحتويه ZIP؟
- موقع الطالب الكامل.
- لوحة `trans` الاحترافية.
- إدارة الفصول من الموقع.
- التقرير النهائي + طباعة/حفظ PDF + CSV.
- صفحة إعدادات وفحص اتصال.
- Workflow n8n V2.0 مبني فوق V1.3 العامل.
- شعار وزارة التعليم.

## مهم جدًا قبل التفعيل
Workflow V2 يستخدم نفس مسارات Webhook الموجودة حاليًا:
- `student-transfer-1448-v1`
- `student-transfer-1448-trans-v1`

لذلك:
1. استورد ملف `n8n/student-transfer-1448-v2-complete.json`.
2. تأكد من Google Sheets Credential إذا طلب n8n إعادة اختياره.
3. عطّل Workflow V1.3 القديم فقط.
4. فعّل V2.0.
5. لا تشغل V1.3 وV2 معًا لأنهما يستخدمان نفس Webhooks.

## إدارة الفصول
من:
`/trans/classes.html`

لكل فصل:
- العدد الحالي: محسوب تلقائيًا من الطلاب.
- متاح لاستقبال النقل:
  - نعم = يظهر للطالب.
  - لا = لا يظهر للطالب، كما يرفض Backend إرسال طلب إليه.
- مستبعد من الموازنة: لا يدخل في حساب الهدف.
- العدد المستهدف: يدوي أو تلقائي.
- ملاحظة الإدارة.

## التقرير النهائي
من:
`/trans/report.html`

التقرير يشمل:
- إجمالي الطلاب والطلبات.
- المعلق والمقبول والمرفوض.
- أعداد كل فصل.
- الهدف والمقترح والاحتياج أو الفائض.
- الفصول المغلقة والمستبعدة.
- خطة موازنة حسابية مقترحة.
- جميع الطلبات والقرارات.
- تاريخ القرار واعتمد بواسطة.
- طباعة / حفظ PDF.
- تصدير CSV.

## لماذا كان التقرير القديم قد لا يعمل؟
الإصدار السابق كان يفتح التقرير في تبويب جديد مع Session Storage، وهذا قد يفقد جلسة دخول trans.
في V2 جميع روابط لوحة الإدارة تنتقل في نفس الجلسة، والتقرير يتحقق من الجلسة قبل جلب البيانات.

## الأمان
ملف Workflow يحتوي على مفتاح trans الحالي حتى يعمل بعد الاستيراد دون تغيير تجربة الدخول.
لا ترفع ملف Workflow إلى GitHub عام، ولا تشارك ZIP علنًا.
يفضل لاحقًا تغيير المفتاح إلى قيمة طويلة وعشوائية.
